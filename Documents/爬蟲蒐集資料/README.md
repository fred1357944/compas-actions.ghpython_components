# 富邦證券排行榜爬蟲系統 v1.0

## 專案概述
這是一個專業的台股資料爬蟲系統，專門設計用於從富邦證券網站自動擷取各類股市排行榜資料，協助投資決策分析。

## 版本資訊
- **版本**: v1.0
- **發布日期**: 2025-09-01
- **作者**: 系統自動生成（使用Claude Code協助開發）

## 主要功能

### 🎯 核心特色
1. **智能判斷機制** - 自動判斷資料可用性（交易日、T+N日延遲）
2. **多維度資料收集** - 涵蓋價格、成交量、成交值、法人動向等多個面向
3. **錯誤處理與重試** - 內建錯誤處理與自動重試機制
4. **狀態追蹤記錄** - 詳細記錄每次執行狀態與結果

### 📊 資料涵蓋範圍

#### 收盤價類
- 漲幅排行（前50名）
- 跌幅排行（前50名）
- 漲停表
- 跌停表

#### 成交量類
- 量大排行
- 量增排行
- 量縮排行
- 量增幅排行
- 量縮幅排行
- 週轉率排行

#### 成交值類
- 值大排行
- 值增排行
- 值縮排行
- 值增幅排行
- 值縮幅排行

#### 法人/主力進出（T+1日更新）
- 外資買超/賣超/買賣超排行
- 自營商買超/賣超/買賣超排行
- 投信買超/賣超/買賣超排行
- 主力買超/賣超排行

#### 強勢股分析
- 當日強勢股

## 安裝與設定

### 環境需求
- Python 3.8+
- macOS/Linux/Windows

### 安裝步驟
```bash
# 1. 安裝必要套件
pip install pandas openpyxl beautifulsoup4 lxml playwright httpx aiofiles

# 2. 安裝Playwright瀏覽器
playwright install chromium

# 3. (選用) 建立虛擬環境
python -m venv fubon-env
source fubon-env/bin/activate  # macOS/Linux
```

## 注意事項

### 執行時機建議
1. **最佳時間**: 交易日 15:30 後（確保收盤資料完整）
2. **法人資料**: T+1日才會更新（建議隔日執行）
3. **強勢股資料**: 需要累積多日資料（三日、五日等）

### 已知限制
1. 部分法人資料在月初可能無資料（如9月1日）
2. 非交易日（週末、國定假日）不會有新資料
3. 強勢股資料需要累積足夠交易日才會產生

### 資料更新頻率
- **即時類**: 收盤價、成交量、成交值（當日收盤後）
- **T+1類**: 法人買賣超資料（隔日下午）
- **累積類**: 強勢股資料（需T+N日）

## 技術架構

- **輸出格式**: Excel (openpyxl)

2. **並行處理**: 多執行緒加速爬取
3. **錯誤恢復**: 自動重試與錯誤處理
4. **狀態追蹤**: JSON格式的狀態記錄
